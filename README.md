# Family Budget

Семейный бюджет на двоих — **не учёт расходов, а распределение доходов**.

Вася и Лена знают, сколько получат в этом месяце, но деньги приходят в разное время и частями.
Приложение отвечает на вопрос: **кому, сколько и в какую категорию положить** — за месяц целиком и
из каждого конкретного поступления.

## Словарь

| Термин                  | Что это                                                                                        |
| ----------------------- | ---------------------------------------------------------------------------------------------- |
| Семья                   | Двое участников; владелец создаёт семью и приглашает второго по коду                           |
| Категория               | Куда идут деньги: фиксированная сумма или процент от дохода                                    |
| Деление                 | Как обязательство по категории режется между участниками: пополам или пропорционально доходу   |
| Расчётный период, месяц | Всегда первое число: `2026-08-01`. В URL — `?period=2026-08`                                   |
| Плановый доход          | Сколько участник ждёт за месяц                                                                 |
| Поступление (транш)     | Фактически пришедшие деньги; разбиваются по категориям пропорционально вкладам участника       |
| Личный остаток          | Что остаётся участнику после категорий; политика `equalized` выравнивает его переводом другому |
| Закрытие месяца         | Необратимая фиксация расчёта; план и состав категорий замораживаются, поступления — нет        |

Правила — [docs/domain/rules.md](docs/domain/rules.md)

Расчёт распределения — [docs/domain/distribution.md](docs/domain/distribution.md).

## Стек

pnpm-монорепозиторий · Next.js 16 (App Router) · Drizzle + Postgres 16 · MobX + mobx-tanstack-query ·
zod · next-safe-action · shadcn/ui · vitest · Docker Compose · just

## Быстрый старт

Нужны: Node.js 24, pnpm 11, Docker, [just](https://github.com/casey/just).

```bash
cp .env.example .env   # заполнить пароли и SESSION_SECRET
pnpm install
just migrate           # поднимет Postgres и применит миграции
just dev               # http://localhost:3000
```

При первом запуске Postgres создаёт две роли (`docker/postgres/initdb/10-roles.sh`, имена — из
`MIGRATE_DB_USER` и `APP_DB_USER` в `.env`): роль миграций владеет схемой, роль приложения только
читает и пишет данные (ADR-0012).
Нужную роль подставляет `scripts/with-db-env.sh`, поэтому команды, которым нужна БД, запускаются
через `just`, а не голым `pnpm`.

## Команды

| Команда                                     | Что делает                                                       |
| ------------------------------------------- | ---------------------------------------------------------------- |
| `just dev`                                  | Postgres + `next dev` под ролью `app`                            |
| `just migrate`                              | применить миграции под ролью `migrate`                           |
| `just generate`                             | сгенерировать миграцию после правки схемы в `packages/database`  |
| `just studio`                               | Drizzle Studio                                                   |
| `pnpm typecheck`                            | `tsc` по всем пакетам — обязательно после любой правки           |
| `pnpm lint` / `pnpm format`                 | ESLint / Prettier                                                |
| `pnpm test`                                 | vitest                                                           |
| `pnpm check`                                | format:check + lint + typecheck                                  |
| `just build` / `just prod-up`               | образы `web` и `migrate` с тегом по git SHA, запуск с бэкапом БД |
| `just rollback <sha>`                       | вернуть `web` на предыдущий образ                                |
| `just db-backup` / `just db-restore <file>` | `pg_dump` в `backups/` / восстановление                          |
| `just health`                               | `/api/health/live` и `/ready` прод-контейнера (порт 3001)        |

## Карта репозитория

```
packages/
  domain/      общий словарь сервера и клиента: zod-контракты, ошибки, деньги, даты, расчёт распределения
  database/    схема Drizzle и миграции (server-only)
  ui/          shadcn-компоненты
apps/web/
  app/         страницы и route handlers
  features/    клиентские фичи (эталон — monthly-budget)
  components/  общий UI без знания фич
  client/      клиентская половина модулей: кэш, чтение, команды, live-sync
  lib/         серверные модули: сценарии, транзакции, события
docker/, Dockerfile, docker-compose*.yml, justfile   контейнеризация
docs/        решения (adr/) и правила расчёта (domain/)
```
