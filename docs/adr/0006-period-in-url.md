# 0006. Выбранный месяц хранится в URL

Статус: принято, 2026-09-30

## Контекст

Ссылкой на месяц должно быть можно поделиться, кнопки «назад» и «вперёд» должны листать месяцы, а
перезагрузка — не сбрасывать выбор. Календарь нужен в шапке до того, как придут данные бюджета, и
не только на экране бюджета.

## Решение

- Месяц — параметр `?period=2026-08`. Он есть в URL всегда: `proxy.ts` редиректит адрес без него
  или с мусором на текущий месяц.
- Разбор и формат параметра — одни функции из `domain` для сервера и клиента.
- Писать в параметр может только `features/month-navigation`, через `history.pushState`. Читают
  все остальные через `useSelectedPeriod`.

## Альтернативы

- Хранить месяц в сторе: не переживает перезагрузку, и получается второй источник истины рядом с
  URL.
- Менять месяц через `router.push`: каждый клик — серверный рендер с гардами. `pushState`
  обновляет `useSearchParams` без запроса, данные подтягивает клиентский кэш.
- Сегмент пути `/incomes/[period]`: смена месяца перемонтирует страницу, теряются выбор участника
  и SSE-соединение.

## Последствия

- Смена месяца не ходит на сервер, если месяц уже в кэше.
- Вход без параметра стоит лишнего редиректа.
- В MobX месяц приходит на кадр позже рендера, поэтому модель считает данные чужого месяца
  загрузкой, а не показывает их.
