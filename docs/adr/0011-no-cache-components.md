# 0011. Не включаем Cache Components

Статус: принято, 2026-09-30 (Next 16.3)

## Контекст

Next 16 предлагает `cacheComponents: true`: `use cache`, частичный пререндер статической оболочки,
`<Activity>` для скрытых страниц.

## Решение

Не включаем. Стриминг данных через `<Suspense>` работает и без флага.

## Почему

- Вся внутренняя часть приложения закрыта авторизацией и персональна. В статическую оболочку
  попали бы только шапки.
- `await requireUser()` в layout вне Suspense с флагом — ошибка сборки. `getCurrentPeriod()` и
  `dehydrate()` читают текущее время, это тоже придётся переделывать.
- `<Activity>` меняет поведение всего приложения: диалоги и формы переживут уход со страницы.
- Данные бюджета живые (SSE и `version`), кэшировать их на сервере нечего.

## Пересмотреть, если

Появятся публичные страницы со статикой или понадобится сохранять состояние экрана между
переходами. До включения: вынести гард из layout, обернуть время в `io()`, проверить диалоги.
